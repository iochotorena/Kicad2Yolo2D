# Output

This folder contains all generated output files from the Kicad2Yolo2D project.

## Subdirectories

- **datasets/**: YOLO training datasets generated from KiCad component data
- **images/**: Processed and extracted images for training
- **labels/**: YOLO format label files corresponding to the images

## Note

This folder is for generated output files. Contents may be added to `.gitignore` depending on project needs.
