Input Folder - File Requirements
================================

This folder contains example KiCad project files that demonstrate the expected file structure.

The example files in this folder serve as a reference for the types of files that should be 
placed here for processing. When adding your own KiCad projects to this folder, ensure that 
your files have the same extensions as the example files.

Required File Extensions:
-------------------------
Based on the example files in this folder, the following file extensions are expected:

- .kicad_pcb  - KiCad PCB board file
- .kicad_prl  - KiCad project local settings file
- .kicad_pro  - KiCad project file
- .kicad_sch  - KiCad schematic file
- .kicad_sym  - KiCad symbol library file

Note: Not all file types may be required for every project, but these are the extensions 
that are commonly used in KiCad projects and are supported by this tool.

Usage:
------
Place your KiCad project files in this folder to have them processed for extracting 
component placement data and creating YOLO training datasets.
